## Projetos em destaque: texto proposto

### 01 · MeuSemestreUCSAL — produto para estudantes

Plataforma independente para avaliar professores e planejar a grade de horários. Reúne autenticação por e-mail, avaliações, moderação e organização da experiência do aluno.

**Competências demonstradas:** desenvolvimento Full Stack, autenticação, modelagem de dados e interfaces de produto.

**Tecnologias:** Next.js · React · TypeScript · PostgreSQL/Supabase · Tailwind CSS.

[Código e documentação](https://github.com/ViniciusLgo/MeuSemestreUcsal)

### 02 · SGQ — processos, permissões e rastreabilidade

Sistema para registrar e acompanhar reclamações de clientes, não conformidades e recalls. O projeto documenta fluxos de aprovação, perfis de acesso, auditoria e rastreabilidade dos requisitos.

**Competências demonstradas:** regras de negócio, autorização, persistência relacional, testes e documentação técnica.

**Tecnologias:** C# · .NET 10 · ASP.NET Core MVC · Entity Framework Core · PostgreSQL.

[Código e documentação](https://github.com/ViniciusLgo/SGQ)

### 03 · Microcrédito — dados públicos e processamento

Projeto acadêmico em equipe sobre microcrédito e inclusão financeira regional. Integra dados abertos do Banco Central, tratamento em Python, modelagem dimensional e carga em PostgreSQL. O repositório também contém configuração de infraestrutura em Terraform.

**Competências demonstradas:** ETL, tratamento de dados, SQL, modelagem dimensional e colaboração.

**Tecnologias:** Python · pandas · PostgreSQL · Terraform.

[Código e documentação](https://github.com/ViniciusLgo/bigdata-microcredito-project)

### 04 · Thiago Guinchos — interface e narrativa em 3D

Protótipo de site institucional com uma cena de resgate em Three.js conduzida pela rolagem. Inclui adaptação para celular, alternativa sem WebGL e tratamento para preferência por movimento reduzido.

**Competências demonstradas:** desenvolvimento de interfaces, animação 3D, acessibilidade e adaptação a dispositivos.

**Tecnologias:** JavaScript · Three.js · HTML · CSS.

[Código e documentação](https://github.com/ViniciusLgo/thiago-guinchos-site)

### 05 · MovieFlix — API com Java e Spring

Projeto de estudo do curso Java 10x para gerenciar filmes, categorias e serviços de streaming. Documenta autenticação JWT, validação, persistência e documentação OpenAPI.

**Competências demonstradas:** APIs REST, autenticação e modelagem relacional.

**Tecnologias:** Java · Spring Boot · Spring Security · PostgreSQL · Flyway.

[Código e documentação](https://github.com/ViniciusLgo/Movieflix)

### 06 · GuinchoTrack — componentes e estado no React

Projeto acadêmico de painel de frota com filtros, paginação, abas e notificações. Exercita componentes reutilizáveis, gerenciamento de estado e Context API.

**Tecnologias:** React · JavaScript · CSS.

[Código e documentação](https://github.com/ViniciusLgo/guinchotrack)

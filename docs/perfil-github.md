## Manutenção editorial

Ao incluir um projeto, registrar problema, contribuição, tecnologias e link de evidência. Identificar estudos, trabalhos em equipe e protótipos. Só usar números de usuários, resultados e estado de produção quando houver confirmação atual.

Os banners são SVGs locais, sem fontes remotas ou scripts. A versão de celular é selecionada por `<picture>`. Todo conteúdo essencial também existe como texto no README.
